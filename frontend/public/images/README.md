# TCET Event Images

Drop your images here! Then use them in the website like:

## Hero Image (campus photo)
Put your TCET campus photo here and name it: `campus.jpg`
Then update Home.jsx to use it.

## Event Images
Name your event photos like:
- techfest.jpg
- cultural-night.jpg
- hackathon.jpg
- sports-day.jpg
- workshop.jpg
- guest-lecture.jpg

You can set these as image URLs when creating/editing events in the admin panel.
Use the path: /images/techfest.jpg (etc.)
